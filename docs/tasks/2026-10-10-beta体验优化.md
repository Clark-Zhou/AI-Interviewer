## 目标与范围

处理首位试用反馈的四项问题：生成问题和评价时桌面与手机自动定位、主页云端存储文案、历史页记录列表按钮文案、AI 评价的求职练习语气。

非目标：改变 API 或评价 JSON 结构、历史记录格式、旧记录内容、云端保存机制、未完成面试保护；不新增依赖。

## 验收标准

- 生成问题点击后看到加载区，成功后定位问题标题，失败后定位错误提示；真实、重试和 Mock 路径一致。
- 生成评价点击后看到加载状态，成功后定位评价标题与分数，失败后定位错误提示；真实、重试和 Mock 路径一致。
- 过期请求不触发滚动；键盘焦点可访问，减少动态效果设置生效，手机底栏不遮挡目标。
- 主页正确说明面试历史与简历仓库按账号云端保存；历史页按钮使用“记录列表”而非“左栏”。
- 后续真实 AI 评价以求职者练习为视角，避免招聘决策措辞，保留现有数据结构。
- 构建、差异检查和必要回归完成；功能验收方式由用户在代码完成后决定。
