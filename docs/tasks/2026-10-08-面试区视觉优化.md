## 目标与范围

统一受保护面试区的宽度、间距和视觉层级，改善边线错位、宽屏空白及页面单调问题。桌面保留顶部五入口，手机保留固定底栏；把邮箱及登出从共享页头一起移至个人中心。

非目标：主页和登录页改版、API、历史格式、Auth 方式、简历存储、统计、资料编辑或新增依赖。

## 验收标准

- 账号区、导航和内容使用一致的约 1200px 宽度及页面间距；桌面 1280/1440px 与手机 390px、窄屏无明显错位、横向溢出或底栏遮挡。
- 面试区的字体、标题、卡片、表单、按钮、焦点与导航图标一致；工作台中央强调和当前页高亮清晰。
- 工作台只有新建面试操作与静态三步引导；新面试、历史交互及数据保持可用；简历仓库保留新建面试链接。
- 只有个人中心展示当前邮箱和登出；从未保存的新面试前往个人中心时仍可取消离开。
- 构建、差异检查通过，提供桌面和手机截图，完成独立 session 审查。

## 已确认计划

按用户提供的“面试区视觉优化与账号入口调整”计划实施：约 1200px 统一容器，浅色整页背景、克制青绿色渐变和 CSS 抽象图形；桌面品牌加顶部导航，手机品牌加底栏。共享布局继续登录保护与离开保护，个人中心服务端读取用户并挂载现有账号操作。仅调整面试区视觉与直接受影响的文档。上一导航任务未完成的手动验收仍保留在原记录。

## 实施与验证结果

- 共享布局改为品牌加五入口导航，账号组件只挂载在个人中心；个人中心服务端读取当前用户邮箱。导航加入少量 SVG 图标，页面链接继续使用原生跳转。
- 面试区新增约 1200px 统一容器、浅色背景、抽象图形、响应式卡片/表单/按钮样式；工作台新增静态三步引导，历史与新面试沿用原交互和数据。
- `npm run build` 与 `git diff --check` 通过。生产服务中未登录访问 `/interview` 及五个子路由均返回 307 到 `/login`。
- 浏览器打开本地受保护页面后进入登录页。用户选择先保留登录后验收缺口，因此桌面 1280/1440px、手机 390px 和窄屏视觉检查、真实页面截图、账号只在个人中心出现、登出、未保存面试跳往个人中心时取消离开均未完成，不标记为通过。独立审查可先核对代码与构建，之后仍需补齐浏览器验收。
