## 目标与范围

将完整面试历史从浏览器 `localStorage` 改为按 Supabase 账号隔离的云端记录；保留列表、详情、单条删除和清空全部。云端不限数量，按 20 条分页。旧本地记录只由当前账号确认后手动导入，并保留浏览器原件。

非目标：自动迁移、离线暂存、恢复历史到当前面试、搜索、统计、原始文件存储、新依赖或 `service_role`。

## 验收标准

- 最终评价（真实 AI 和 Mock）生成后保存云端；只在云端确认成功后解除离开提醒。失败保留评价、可重试且不重复创建记录。
- 登录账号只能查看、创建、删除自己的记录；未登录 API 返回 401。跨设备可查看完整 JD、简历文本、问答和评价。
- 历史列表分页、详情、单条删除及清空全部可用。手动导入旧本地记录需确认潜在跨账号来源；按本地 ID 去重，坏记录逐条跳过并报告，原记录留在本机。
- 构建、差异检查和独立代码审查通过。代码完成后由用户决定人工或 AI 功能验收；结束后提供 PR 标题和描述，由用户手动合并。
