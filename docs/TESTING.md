# Testing

## 文档职责

记录当前长期有效的开发测试边界和核心回归路径。不要为每个阶段永久新增检查点；一次性验收见对应任务记录。

## 测试边界

- AI session 的依赖安装、服务启动和权限边界统一以 `AGENTS.md` 为准，本文件不重复维护。
- 不真实调用 DeepSeek，除非用户明确要求或任务必须验证真实 AI。
- 生产环境不应显示 Mock 按钮。
- 云端历史需先执行建表和 RLS SQL；至少用两个账号验证隔离。旧浏览器 `localStorage` 仅供手动导入。
- 简历仓库需先完成私有桶、元数据表、RLS 和服务端令牌配置；云端功能必须用至少两个登录账号验证隔离。

## 当前开发辅助能力

开发环境 `process.env.NODE_ENV === 'development'` 下可见：

- `填入示例 JD/简历`：填入固定测试输入，并清空上一轮状态。
- `使用 Mock 问题`：使用本地固定问题，不调用后端 API。
- `填入测试回答`：根据当前问题生成本地测试回答。
- `使用 Mock 评价`：生成本地固定评价，不调用后端 API，并复用历史保存链路。

## 核心回归清单

登录与入口：

- `/` 显示主页、登录/登出入口、面试入口和登录状态。
- 未登录点击面试入口进入 `/login`。
- 登录或注册取得会话后回到 `/`，首次到达就显示已登录状态与面试入口；刷新主页后仍保持登录，不应要求再次输入密码。
- 注册必须填写昵称；验证纯英文、纯汉字和混合昵称的 14 个长度单位边界，以及空值、空格、数字、符号和超长输入的错误提示。
- 已登录用户可进入 `/interview`，刷新后仍保持登录态。
- 面试区五入口顺序为简历仓库、历史记录、工作台、数据和分析、个人中心；新面试页仍高亮工作台，账户子页面仍高亮个人中心。
- 桌面导航在顶部、手机导航在底部；当前页、高亮、键盘焦点清晰，底栏不遮挡内容。
- 面试区账号邮箱和登出按钮只出现在 `/interview/profile/account`；个人中心总览、工作台、新面试、简历仓库、历史记录和数据和分析均不显示。桌面与手机容器对齐，无横向溢出。
- 个人中心总览的头像与昵称可用键盘进入账户页；主题外观、使用手册、建议和反馈、关于我们、更多设置仅是静态条目，没有可点击控件。
- 账户页的已有无昵称账号显示“面试用户”；修改昵称后账户页与个人中心总览更新，重新登录后仍显示新昵称。邮箱和手机号只读。
- 账户页密码行显示固定 `********`，没有显示密码控件；验证当前密码错误、两次新密码不一致、修改成功后用新密码登录，以及取消后清空输入。
- 未登录直接访问五个面试区页面、新面试页和账户子页面都会进入 `/login`。
- 登出后回到未登录状态。

新面试流程：

- `/interview` 只提供新建面试操作和静态三步引导；简历仓库可跳转新面试，数据和分析为页面骨架；个人中心展示默认头像、昵称及静态模块列表，账户子页面展示账号资料、昵称与密码修改入口和登出。
- `/interview/new` 初始状态不显示历史记录区，也不显示问题空面板。
- `/interview/new` 显示可选岗位名称输入；岗位名称为空时仍可生成问题。
- JD 或简历为空时，点击生成问题会提示错误。
- 生成问题后展示问题列表、分类、问题文本和原因。
- 生成问题时，桌面和手机点击后定位加载区，成功后定位“模拟问题”，失败和重试失败后定位错误；Mock 问题成功也定位标题。修改输入或重置后，过期请求不能再改变结果或滚动位置。
- 每题可单独提交，也可一键提交全部回答。
- 所有题提交后才能生成最终评价。
- 最终评价展示总分、总结、优势、风险点、建议、逐题反馈和后续练习。
- 生成最终评价时，桌面和手机点击后定位加载提示，成功后定位“最终评价”与分数，失败和重试失败后定位错误；Mock 评价成功也定位标题。目标可用键盘焦点访问，减少动态效果时不播放平滑滚动，手机底栏不遮挡目标。
- 生成问题或最终评价失败后可重试。
- `开始新一轮` 清空当前输入、问题、回答、提交状态、评价和提示，但不删除历史。
- 未完成面试离开、返回、刷新、关闭或登出前提示确认；取消后内容仍在。云端确认保存最终评价后不提示，保存失败或成功后再次编辑则继续提示；失败可用同一 ID 重试。

文件输入：

- JD 和简历输入区支持 `.txt` / `.md` 本地导入。
- JD 和简历输入区支持文本型 `.pdf` / `.docx` 后端解析。
- 导入或解析成功后文本进入现有 textarea，用户仍可编辑。
- 导入或解析成功后清空旧问题、回答、提交状态、评价和保存提示。
- 不支持类型、空文件、文件过大、读取失败、解析失败、解析为空和扫描版 PDF 都有明确提示。
- 新面试当次导入的原始文件、文件名和路径不写入历史记录、localStorage、数据库或日志；主动上传仓库时，仅原文件进入私有 Storage，文件名等元数据进入账号隔离的数据表。
- 新面试从电脑导入只用于当次；从简历仓库选取后文本进入可编辑 textarea，旧问题和评价清空，失败时原输入保留。

简历仓库：

- PDF、DOCX、TXT、MD 可上传并跨设备出现在同一账号列表；原文件可下载，删除后消失。
- 账号各自最多 10 份，并发上传不能突破上限；删除后可补位，同名文件可共存。
- 空文件、超限文件、伪造扩展名、损坏或加密文档、扫描版 PDF 和非 UTF-8 文本均拒绝入库且不占名额。PDF 解析时显式关闭 `pageJoiner`，判空只看正文，不能把解析库附加的页码分隔符当作简历文字。
- 第二个账号不能查看、下载、删除或选用第一个账号的简历；未登录直接请求仓库 API 返回 401。

历史记录：

- 最终评价（真实 AI 与 Mock）生成后新增当前账号云端历史；失败保留评价和重试入口，重试不重复创建。
- 旧本地历史的 `localStorage` key 为 `ai-interview-sessions`，仅手动导入时读取，导入后保留原记录。
- 新记录排在最前，每页 20 条，可继续加载且不自动删除旧记录。
- 新记录保存 `jobTitle`；历史列表和详情优先显示岗位名称。
- 旧记录缺少 `jobTitle` 时，标题 fallback 到岗位信息摘要，再 fallback 到“未命名岗位”。
- 历史列表支持单条删除，删除前需要确认；删除当前选中项后应自动选中剩余第一条，删空后显示空状态。
- 历史页支持清空当前账号全部云端记录，清空前需要确认，旧本地记录不受影响。
- 历史页左侧列表支持收起/展开；左侧列表只显示岗位名称、时间和分数，Mock/AI 来源保留在右侧详情。
- 历史列表收起按钮在桌面和手机均显示“收起记录列表／展开记录列表”；主页云端存储说明与当前数据来源一致。
- 历史详情展示完整岗位 JD、简历文本、问答、整体评价、优势、风险、改进建议、逐题反馈和后续练习题。
- 旧记录缺少 `generationSource` 时仍可展示。
- 手动导入前提示此浏览器的旧记录可能属于其他账号；重复导入按当前账号和旧 ID 去重，损坏或内容不完整的记录计入失败且不阻断其余记录，原始 localStorage 保留。
- 第二个账号不能查看、删除或导入到第一个账号的云端历史；未登录直接请求历史 API 返回 401。

Mock 流程：

- Mock 问题和 Mock 评价只在开发环境显示。
- Mock 按钮由用户显式点击，不自动替代真实 AI。
- Mock 评价复用云端历史保存机制，`generationSource` 标记为 `mock`。
- 真实 AI 流程仍走后端 API 和正式 prompt。
