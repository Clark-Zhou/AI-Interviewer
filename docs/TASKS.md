## 任务卡 #26：主页字体、短文案和信息排版优化

状态：已完成开发、生产构建验证和审查意见修复，待代码审查 session 复审。

目标：在不改变主页业务能力、认证逻辑和右侧封面主体的前提下，让 `/` 以更简洁、高效的文案和更清晰的字体层级呈现产品价值，并为未来帮助页和公告页预留全局入口。

已确认文案：

- Kicker：`AI Interview Simulator`
- 主标题：`面试之前，先练一次`
- 核心说明：`基于岗位 JD 和个人简历生成针对性问题并在作答后提供结构化评价。`
- 隐私提示：`记录仅保存在当前浏览器 · 请使用脱敏信息`
- 未登录主按钮：`开始模拟面试`
- 未登录次按钮：`登录 / 注册`
- 已登录主按钮：`进入面试工作台`
- 已登录状态使用单行轻量信息：`已登录 · 用户邮箱`

范围：

- 主页采用质感更好的中文无衬线字体，首选 `Noto Sans SC`，并提供合理的系统字体 fallback；可以使用 Next.js 已有字体能力，但不增加 npm 依赖或运行时第三方字体 CDN。
- 字体调整只作用于主页，不改变登录页、面试工作台、新面试页和历史页的字体表现。
- 精简主页左侧文案，按 Kicker、主标题、核心说明、入口和轻量提示形成明确层级。
- 保留现有未登录、已登录和 Supabase Auth 未配置三种状态及其原有行为。
- 已登录邮箱不再占用大块状态卡，改为按钮附近的单行辅助信息；错误或配置警告仍需清晰可见。
- 保留现有未登录和已登录入口语义：未登录入口继续前往 `/login`，已登录入口继续前往 `/interview`，退出登录仍可用。
- 在主页顶部导航中预留 `帮助` 和 `公告` 两个可见入口，放在品牌与认证/面试入口之间的导航区域。
- `帮助` 和 `公告` 当前以不可导航的占位状态呈现，并表达“即将开放”；不能链接到不存在的路由或产生 404。
- 保持右侧抽象封面的内容和主体构图不变，只允许为配合新的文字高度做必要的响应式对齐调整。
- 桌面端和移动端都需保持清晰层级，不出现导航拥挤、文字溢出或按钮遮挡。
- 字体实现需可正常构建；如果首选字体方案在当前环境不可用，应退回可靠的系统字体方案，不为此安装依赖。

非目标：

- 不实现 `/help`、`/announcements` 或其他帮助/公告路由。
- 不实现公告红点、未读状态、公告弹窗、公告数据或后台管理。
- 不重做右侧抽象封面，不新增插画、图片或动画。
- 不进行全站字体替换、全站视觉重构或设计系统建设。
- 不改 Supabase Auth、API、prompt、面试流程、历史记录或本地存储逻辑。
- 不新增营销长文案、功能介绍区、用户评价、价格区或页脚内容。
- 不新增依赖。

默认需要阅读：

- `AGENTS.md`
- `docs/HANDOFF.md`
- `docs/TASKS.md`

按需阅读：

- 当前事实读 `docs/STATUS.md`。
- 首页入口关系不清楚时再读 `docs/ARCHITECTURE.md`。
- 本任务不改 API、长期测试流程或产品边界，不需要默认阅读 `docs/API.md`、`docs/TESTING.md`、`docs/PRD.md` 或 `docs/archive/`。

验收标准：

- `/` 使用新的中文无衬线字体方案，中文和英文字符显示协调，并有可用 fallback。
- 首屏左侧只保留已确认的短文案和必要状态信息，没有新增长段落。
- 主标题、核心说明、入口和隐私提示的视觉层级清楚，用户能快速找到主要入口。
- 未登录时，两个入口仍正确前往 `/login`；已登录时可进入 `/interview` 并正常退出登录。
- Supabase Auth 未配置时，原有警告仍可见且可读。
- 顶部导航可看到 `帮助` 和 `公告` 占位入口，并能理解它们尚未开放。
- 点击或操作占位入口不会进入 404、改变路由或触发未实现功能。
- 桌面端和常见移动端宽度下没有溢出、遮挡或明显错位；移动端信息顺序合理。
- 右侧抽象封面主体没有被重做，其他页面视觉和功能不受影响。
- 没有新增依赖，没有改 API、认证协议、历史数据结构或面试业务逻辑。

审查关注点：

- 字体是否只影响主页，且没有通过全局 `body` 意外改变其他页面。
- 是否严格使用确认后的短文案，没有重新扩写成长篇营销内容。
- 帮助/公告是否为真正的不可导航占位，而不是指向不存在路由的链接。
- 占位入口是否仍有可理解的禁用语义和基本可访问性。
- 登录、进入面试、退出登录和 Auth 未配置状态是否保持原行为。
- 是否只对右侧封面做必要对齐，没有扩大为视觉重构。
- 是否检查桌面端和移动端，并避免新增依赖或无关改动。
