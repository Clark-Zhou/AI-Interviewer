# Docs Map

## 文档职责

这是 docs 目录的文档地图，用于帮助人类和 AI session 按需选择文档，减少默认阅读 token 消耗。

## 默认阅读

新的 AI session 默认只读：

- `AGENTS.md`：项目协作规则和硬性边界。
- `docs/HANDOFF.md`：当前交接状态。
- `docs/TASKS.md`：当前任务卡和验收标准。

## 按需阅读

- `docs/STATUS.md`：当前分支、已完成功能、暂缓事项和残余风险。
- `docs/ROADMAP.md`：下一阶段方向和阶段索引。
- `docs/ARCHITECTURE.md`：技术栈、路由、目录结构、数据流和重要文件职责。
- `docs/API.md`：项目 API route 的请求、响应和错误边界。
- `docs/TESTING.md`：当前长期有效的开发测试和回归清单。
- `docs/WORKFLOW.md`：本地运行、环境变量、部署和内部测试流程。
- `docs/PRD.md`：产品目标、用户主流程和 MVP 边界；不是通用必读。
- `docs/templates/session-prompts.md`：多 session 启动提示词模板。
- `docs/archive/`：历史长文档归档，默认不读。

## 旧入口

`docs/PROJECT_STATUS.md`、`docs/DEVELOPMENT_TESTING.md`、`docs/INTERNAL_TESTING_RELEASE.md` 已迁移为兼容提示壳，新任务应改读上面的新文件。
