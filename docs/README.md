# 文档地图

| 场景 | 入口 |
| --- | --- |
| 接手项目、了解执行规则 | [项目协作规范](../AGENTS.md) |
| 寻找尚未完成的较大任务 | [未完成任务](tasks/README.md)；用户指定记录时直接打开该任务 |
| 新建较大任务记录 | [任务模板](templates/task.md) |
| 启动开发、独立审查或继续任务 | [提示词模板](templates/session-prompts.md) |
| 了解已上线能力、限制和风险 | [项目状态](STATUS.md) |
| 讨论未来方向和优先级 | [路线图](ROADMAP.md) |
| 调整产品目标、主流程或 MVP 边界 | [产品需求](PRD.md) |
| 理解技术栈、路由、模块和数据流 | [架构](ARCHITECTURE.md) |
| 调整接口或请求响应协议 | [API](API.md) |
| 验证核心流程、文件导入、历史或 Mock | [测试说明](TESTING.md) |
| 配置本地环境、运行或部署 | [运行说明](WORKFLOW.md) |

完成任务记录保留在 `tasks/` 原路径；既有历史资料保留在 `archive/`。查阅历史的执行规则见项目协作规范。

[Beta 用户反馈](beta-feedback/README.md)供项目所有者阅读。Agent 日常接手不默认读取，只有用户要求或排查相关体验问题时才定向查阅。
