## 已完成功能摘要

- 核心闭环：可选岗位名称 + 岗位 JD + 简历 -> AI 生成 6 道问题 -> 用户逐题回答 -> AI 最终评价。
- 入口与账号：主页 `/`、登录页 `/login`、受保护工作台 `/interview`、新面试 `/interview/new`、历史记录 `/interview/history`。
- 主页：使用仅作用于 `/` 的中文无衬线字体栈和精简首屏文案；保留登录/面试/登出行为，并预留不可导航的帮助、公告占位入口。
- Auth：Supabase Auth 邮箱密码注册、登录、登出和登录态保持。
- 新面试：可选岗位名称、空输入校验、生成问题、逐题提交、一键提交全部回答、答题进度、最终评价、错误重试、开始新一轮。
- 开发效率：示例 JD/简历、Mock 问题、Mock 评价、根据当前问题填入测试回答。
- 文件输入：`.txt` / `.md` 浏览器本地导入；文本型 `.pdf` / `.docx` 通过项目后端 API 解析为纯文本。
- 历史记录：最终评价成功后保存到浏览器 `localStorage`，最多保留 10 条，支持列表和详情查看、单条删除、清空全部和左侧列表收起/展开；新记录保存 `jobTitle`，旧记录缺少 `jobTitle` 时按岗位信息摘要 fallback。
- 文档：已完成多 session 协作规范、内部测试准备、轻量 docs 结构和历史归档。

技术栈、路由、目录和数据流以 `docs/ARCHITECTURE.md` 为准。

## 当前限制

- 扫描版 PDF OCR、图片简历识别或复杂文件解析。
- 恢复历史 session 到当前页面。
- 历史记录编辑、搜索和云同步。
- 数据库或云端同步历史记录。
- 用户资料页、OAuth、支付或权限系统。
- AI 逐步提问、多轮追问、单题即时 AI 批改。
- 语音或视频面试。
- 复杂视觉重构或全站设计系统重构。

## 已知残余风险

- `/api/parse-document` 的 5MB 文件大小限制发生在 `request.formData()` 之后；超大 multipart 请求仍可能先进入 Next.js formData 解析流程并占用内存。后续如需更可靠防护，应在部署平台、反向代理或更底层请求体配置中增加更早的 body size 限制。
- 历史记录保存在浏览器 localStorage；换浏览器、换设备或清理浏览器数据后不可恢复。
- 真实 AI 质量依赖 DeepSeek 返回结果和解析器容错，仍需人工观察生成质量。
