# PRD

## 文档职责

记录 AI Interview Simulator 的产品目标、核心用户流程、MVP 范围和非目标。PRD 不是通用必读；只有产品目标、用户主流程、MVP 边界或非目标变化时才读或改。

## 产品概述

AI Interview Simulator 是一个个人模拟面试准备工具。用户提供目标岗位 JD 和个人简历，系统生成定制化面试问题，收集用户回答，并给出结构化最终评价。

核心验证问题：AI 能否帮助求职者围绕一个具体岗位进行有针对性的面试准备。

## 目标用户

- 正在准备面试的求职者。
- 手里有具体岗位 JD。
- 希望根据自己的简历提前练习可能被问到的问题。
- 希望知道回答是否有说服力，以及哪里需要改进。

## MVP 目标

完成一条可用闭环：

```text
用户输入 JD 和简历 -> AI 生成问题 -> 用户回答 -> AI 生成最终评价 -> 保存账号云端历史
```

MVP 优先保证流程完整、问题相关、反馈可用，不追求复杂账号体系、语音视频或自动化求职管理。

## 核心用户流程

1. 用户打开主页 `/`。
2. 未登录用户进入 `/login` 注册或登录。
3. 登录后回到主页，再进入受保护的 `/interview` 工作台。
4. 用户通过面试区导航进入工作台、历史记录或其他页面；工作台提供新建面试入口。
5. 开始新面试时，用户可填写岗位名称，并输入或导入岗位 JD；简历可从电脑当次导入，也可从账号简历仓库选择。
6. 用户点击生成面试问题。
7. 系统生成 6 道结构化问题，每题包含分类、问题和提问原因。
8. 用户逐题输入并提交回答，也可以一键提交全部回答。
9. 所有回答提交后，用户生成最终评价。
10. 系统展示总分、总结、优势、风险点、改进建议、逐题反馈和后续练习题。
11. 最终评价成功后，系统保存当前账号的云端历史记录；保存失败可在本页重试。

## MVP 功能范围

### 入口和账号

- 主页展示产品入口、登录/登出入口、面试入口和登录状态。
- Supabase Auth 支持邮箱密码注册、登录、登出和登录态保持；注册时要求昵称，昵称仅用于用户界面展示。
- 未登录用户访问面试区时进入 `/login`。
- 面试区提供简历仓库、历史记录、工作台、数据和分析、个人中心五入口导航；工作台位于中间并突出显示。
- 简历仓库可按账号保存最多 10 份可提取文本的原始简历文件，支持上传、下载、删除；数据和分析仍为页面骨架。个人中心提供账户入口与静态模块列表，账户页可修改昵称和密码，并展示邮箱、手机号绑定状态和登出。

### 新面试

- 岗位名称 `jobTitle` 是可选输入，用于历史记录标题和 AI 上下文辅助。
- JD 和简历都使用 textarea 作为最终输入载体。
- 支持手动粘贴 JD 和简历文本。
- 支持 `.txt` / `.md` 本地导入到 textarea。
- 支持文本型 `.pdf` / `.docx` 通过项目后端 API 解析为纯文本后填入 textarea。
- 个人简历也可从账号简历仓库选择并填入 textarea；从电脑导入仅供当前面试使用，不自动保存到仓库。
- 文件导入或解析成功后，用户仍可继续编辑文本。
- 生成问题前校验 JD 和简历不能为空。
- 问题生成后展示问题列表。
- 用户可以逐题提交回答，也可以一键提交全部回答。
- 所有回答提交后才能生成最终评价。
- 有未保存的面试内容时，离开页面前提醒；最终评价成功保存后允许直接离开。

### AI 反馈

- 问题生成和最终评价都通过项目后端 API 调用 DeepSeek。
- 前端不能直接调用 DeepSeek 或暴露 API Key。
- 最终评价应包括整体评价和逐题反馈。
- 失败时给出错误提示和重试入口。

### 历史记录

- 最终评价成功后将完整 session 保存到当前账号的云端历史；保存失败时保留评价和重试入口。
- 云端历史不自动删除，按 20 条分页加载。
- 支持当前账号的云端历史列表和详情查看。
- 支持删除单条云端历史记录和清空当前账号全部云端历史记录。
- 历史记录列表优先用岗位名称作为标题；旧记录没有岗位名称时 fallback 到 JD 摘要。
- 历史记录随账号跨设备同步；旧浏览器本地记录需经当前账号确认后手动导入并去重，浏览器原件保留。

### 简历仓库

- 原文件保存在私有云端存储中，元数据按账号隔离；同一账号可跨设备使用。
- 支持 PDF、DOCX、TXT、MD；上传前须能提取可用文本，扫描版 PDF 不入库。
- 每账号最多保存 10 份；同名文件可共存，删除后释放名额。
- 可下载原文件；选取仓库简历只把文本复制到当前新面试，不修改仓库文件。

### 开发辅助

- 开发环境支持示例 JD/简历、Mock 问题、Mock 评价和测试回答。
- Mock 能力只用于开发测试，不应出现在生产环境。

## 非目标

当前不做：

- 简历之外的云端文件存储或文件管理。
- 扫描版 PDF OCR、图片简历识别或复杂文件解析。
- `.doc` 老格式解析或多文件合并。
- AI 自动结构化 JD/简历。
- AI 逐步提问、多轮追问或单题即时批改。
- 语音或视频面试。
- 头像修改、手机号绑定、OAuth、支付、权限或用量系统。
- 在仓库中创建或编辑简历、重命名或预览文件、面试数据统计分析。
- 完整设计系统或大规模视觉重构。

## 成功标准

- 用户能在几分钟内完成一轮基于目标岗位的模拟面试。
- 生成问题与 JD 和简历明显相关。
- 最终评价能给出可执行的改进建议。
- 开发者能用 Mock 和文件导入快速完成本地回归。
- 新功能不破坏现有 AI、Auth、历史记录和文件解析边界。
